# Projetplongeur
Trouver le spot de plongee dans le monde
L'objectif est de développer une application web proposant un tableau de bord gratuit destiné aux plongeurs. L'outil permettra de consulter les conditions météorologiques marines et les horaires des marées pour différents spots de plongée dans le monde. Le projet inclut la création d'une interface publique gratuite, d'une base de données, et d'un espace d'administration sécurisé pour la gestion du site.
